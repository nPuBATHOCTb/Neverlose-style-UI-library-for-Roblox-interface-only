# NeverloseUI

Neverlose-style UI library for Roblox. **interface only** — no cheat features, no exploits, no game logic. just a nice-looking menu.

> made in 2 days. russian author, english docs.

## features

- neverlose-style dark design with blue accent
- tab system with icons
- animated toggle switches
- sliders with drag support
- dropdown menus
- gear options with popup sliders (e.g. Backtrack, Extrapolation)
- blur effect behind the menu
- user profile (avatar, nickname, session timer)
- smooth open/close animation

## hotkeys

| key | action |
|-----|--------|
| `right Shift` | open / close menu |

## installation

1. open Roblox Studio
2. insert a `LocalScript` inside `StarterGui`
3. paste contents of `luau-nl` file
4. press **play** (F5)



# NeverloseUI

UI-библиотека в стиле Neverlose для roblox. **только интерфейс** — никаких читов, эксплойтов и игровой логики. просто красивое меню.

> Сделано за 2 дня. Автор — русский.

## возможности

- тёмный дизайн в стиле Neverlose с голубым акцентом
- система табов с иконками
- анимированные тумблеры
- слайдеры с поддержкой перетаскивания
- дропдауны (выпадающие списки)
- шестерёнки с всплывающими мини-окошками (например, Backtrack, Extrapolation)
- блюр-эффект за меню
- профиль юзера (аватарка, ник, таймер сессии)
- плавная анимация открытия/закрытия

## горячие клавиши

| клавиша | действие |
|---------|----------|
| `Right Shift` | открыть / закрыть меню |

## установка

1. открой Roblox Studio
2. вставь `LocalScript` внутрь `StarterGui`
3. вставь содержимое файла `luau-nl`
4. нажми **Play** (F5)
